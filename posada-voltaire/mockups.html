Architecture

Four layers, each doing one job well.

Identity is separated from the ballot by construction, the ballot is separated from the count, and the count is separated from any single party. No layer can betray the one below it.

Layer 0
Identity

Who is a unique human

Posada DID stack on the Hyperledger Identus / Atala PRISM EdgeAgent SDK. Gov‑ID + on‑device liveness → a zero‑knowledge personhood credential → one anonymous, unlinkable voter credential.

Layer 3
Anchor & tally

The immutable outcome

Cardano L1 anchors the append‑only bulletin board. Trustees run a threshold decryption of the summed totals only, publishing a proof anyone can re‑verify. To change the result you must rewrite a public blockchain.

Why the outcome can't change

Encryption keeps a ballot secret. Four locks keep the result true.

"Impossible to change the outcome" is not a slogan about strong encryption — encryption hides votes, it does not make results immutable. Integrity is earned by four independent, publicly checkable mechanisms.

Cast‑as‑intended

A Benaloh challenge lets any voter spoil a test ballot and confirm the app encrypted exactly their choice — catching a compromised device without ever creating a receipt.

// spoil → reveal randomness → re‑encrypt fresh

Recorded‑as‑cast

Every accepted ballot is published on an append‑only bulletin board whose Merkle roots are anchored to Cardano L1. Your tracking code proves your ballot is there, unaltered.

// tracking code → Merkle inclusion → L1 anchor

Counted‑as‑recorded

Votes are summed under homomorphic encryption; only the totals are decrypted, with a proof. Anyone can recompute the result from the public ciphertexts — a wrong total can't carry a valid proof.

// homomorphic sum → threshold decrypt + proof

Cannot be rewritten

Altering the result requires forging a STARK proof and rewriting Cardano history and defeating independent verifiers worldwide — simultaneously. Trust does not rest on Posada.

// integrity ≠ availability — both are defended
Posada · Lovelace Manifesto

We reject the idea that connection requires surveillance. Identity must belong to the individual, not the platform. Data must be controlled, not extracted. Choices must be voluntary, not engineered by opaque algorithms.

In a world of behavioral profiling, we choose consent. In a world of algorithmic manipulation, we choose transparency. In a world of digital feudalism, we choose sovereignty. We are not building another engine for engagement — we are building infrastructure for human choice.

The future will not be defined by who controls the largest database. It will be defined by who returns control to the people. We build for those who believe privacy is normal, that autonomy is non‑negotiable, and that technology should expand freedom — not quietly erode it.

This is not disruption.
This is restoration.
